# V4.38 screenshot-driven SmackDown revision

The user supplied a real iPhone screenshot of the opt-in V4.37 showcase,
and it revealed two issues:

1. The *runtime* footer still incorrectly printed **DISPLAY BUILD 4.31**,
   even though the source header and deployed preview were V4.37.
2. Vertical space above the TV's SmackDown presentation was too large while
   the three genuine wrestler photographs were relatively short, with
   rectangular panels competing with the match information below.

V4.38 is a separate review page with NO changes to previous versions:

https://broncos5523.github.io/Inside-the-squared-circle/preview-v4-38-smackdown-broadcast-review.html?show=smackdown&view=showcase

It compresses the masthead, data-health bar and gaps, gives that recovered
height to the real wrestler-photo billboard (16.6cqh -> 21cqh), elevates
the center wrestler photograph, softens the hard frame separators, and
leaves match data, the actual show logo, attribution and scrolling rotation
logic untouched. The footer now accurately displays **V4.38** at runtime.

It deliberately does NOT substitute the previously rejected checkerboard
standalone emblem, invent new photographic subjects, promote ringside
managers as competitors, claim an official Man Cave brand approval, or
rewrite verified dates/results. Portrait images remain photo crops,
NOT transparent cutouts. No new photo-rights claim is made.

This is a QA preview; user's original full-board designs remain the visual
reference, not automatically verified content. A real portrait-TV screen
review is still required before locking it.
