# V4.39 Full Broadcast Composition — Not a cosmetic revision

Requested direction recovered from the original planning and production
conversations: a **premium wrestling-broadcast board**, not a narrow
single-result dashboard with three boxed thumbnail images.

Live preview:
https://broncos5523.github.io/Inside-the-squared-circle/preview-v4-39-smackdown-full-broadcast.html?show=smackdown&view=broadcast

Implemented as an opt-in **separate HTML broadcast stage** within the
existing 9:16 production-capable HTML. The former main layout, separate
28-board sports project, data collectors and all older previews are untouched.

### Why it is materially different

- Large two-sided real SmackDown logo treatment and **provisional**
  metallic silver/gold Man Cave Sports Book Presents / Inside the Squared
  Circle integrated arena header. NOT the rejected checkerboard emblem.
  NOT falsely called the approved finished master custom logo.
- Main arena contains a layered, overlapping, THREE-wrestler photographic
  composition using only wrestler photographs already in the local,
  Wikimedia-attributed, verified asset directory.
- A full horizontal broadcast bar with the actual upcoming schedule/date,
  not unverified claims of the show airing live or a fictitious network.
- Main featured matchup panel, championship watch (ONLY if sourced match
  stipulation mentions championship/title), other published matches,
  actual advertised appearances when present, and an alternative dated
  match list when appearances are not available. No invented appearances.
- Bottom wrestling ticker generated from the source-gated current match
  text, five-show guide, and visible CC BY 2.0 photo credits.
- NO standings, fabricated wrestler rankings, placeholder match winners,
  copyrighted reference-board layout screenshot or made-up championship belt.
- Real metadata is still filtered by the existing schedule/rights safeguards
  in reportedRows. When date-matched data expires, the staged board shows
  an honest next-card update instead of recycling the previous show's facts.

The physical layout now follows the user's reference much more closely:
master-brand arena header -> enormous wrestler photos -> show banner ->
multiple meaningful match/appearance panels -> ticker -> dates.

### Not finished

- The custom master brand logo is NOT final-approved; its typography is
  temporary, no standalone rejected checkerboard art is substituted.
- Photos are licensed 2025 event JPEG crops. They are softened by CSS
  masks/overlap, **not** actual transparent cutouts and they may be outdated
  relative to 2026 attire.
- The available photo inventory covers only four athletes; never falsely
  display unavailable wrestlers or fake their likenesses.
- This is a review preview, not approved Gold Master and not a change to
  production/default route.
- A portrait Fire TV check is needed for text legibility/overflow and
  the user's actual aesthetic approval.

Do not use AI image generation without an explicit new request.
