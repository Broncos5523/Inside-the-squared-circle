## Automatic data update

When hosted over HTTP, this preview checks `money-in-the-bank-preview-data.json` every **five minutes**. Each entrant and supporting match is displayed **only if** `verified: true`, an official HTTPS WWE source URL and a source date are present. The page leaves empty slots in the absence of confirmed announced entrants, rather than inventing a card. Note that this is **display-side auto-refresh only**. No new automated collector, GitHub deployment, or external API integration is included; verified JSON must be supplied by an authorized upstream process.
